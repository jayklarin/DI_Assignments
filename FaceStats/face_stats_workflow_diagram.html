Face Stats — End‑to‑End Workflow Diagram
1. Dataset Acquisition
Synthetic faces • Generated images • Curated datasets → saved in dataset_raw/
⬇
2. Preprocessing (fs01_preprocess_all.py + fs01_preprocessing.ipynb)
Face detection • Landmarks • Alignment • Pose • Cropping • Filtering • Metadata JSON → dataset_preprocessed/
⬇
3. Embeddings & Feature Extraction (fs02 + fs03)
CLIP/InsightFace embeddings • FAISS index • Symmetry • Golden ratio • Skin texture • Ratios → embeddings/
⬇
4. Attractiveness Modeling (fs04_attractiveness_model.ipynb)
Hybrid scoring • Normalization to 1–10 scale • Feature weighting → scores + stats
⬇
5. Inference & Compositing (fs05 + fs06)
Filters (score/gender/age/ethnicity) • Mean face • Weighted composite • PCA reconstruction → composites/
⬇
6. Analysis & Visualization
Distributions • PCA plots • Group comparisons • Outlier detection → analysis notebooks
⬇
7. Presentation Layer
Streamlit UI • Gallery • Dashboards • Composite generator • GitHub documentation
